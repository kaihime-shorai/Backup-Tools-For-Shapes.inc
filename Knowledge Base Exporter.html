Knowledge Base Exporter

Take your Shape's knowledge with you

A short script you paste into your browser's console, which walks your Knowledge tabs and bundles every entry — General, Commands, Relationships, and any custom tabs — into one JSON file you can keep, back up, or move elsewhere.

It only reads what's already on the page in front of you. Nothing is uploaded anywhere — the file goes straight from your browser to your downloads folder.

How it works

  • A floating panel, not a popup. Once you run the script, a small control panel appears in the bottom-right corner of the page and stays out of your way while you work.
  • One tab at a time. Switch to a Knowledge tab, click Capture Tab, then move to the next one and repeat. The panel remembers everything you've captured so far.
  • Download when you're done. Once every tab you care about has been captured, click Download to save the combined file.
1

Open your Shape's Knowledge page

Navigate to the Knowledge page for the Shape you want to export, and land on whichever tab you'd like to capture first — General is a good place to start.

2

Open your browser's console

Press F12, or right-click anywhere on the page and choose Inspect, then open the Console tab.

If your browser warns you about pasting code here: that warning exists because pasted console scripts can do real damage on sites you don't trust. Only run scripts from sources you trust — including this one, so read it over if you'd like before pasting it.

3

Paste and run the script

Copy the script below, paste it into the console, and press Enter. The floating panel should appear immediately in the corner of the page.

(function() {
// 1. Find the shape name
let shapeName = "Shape";
const nameInput = document.querySelector('input[placeholder="tenshi"]') || document.querySelector('input[value="Mihairi"]');
if (nameInput && nameInput.value) shapeName = nameInput.value.trim();

const allTabsData = {};

// 2. Create a non-blocking floating UI panel
const panel = document.createElement('div');
panel.style.cssText = `
    position: fixed;
    bottom: 20px;
    right: 20px;
    background: #1c1c20;
    color: #e7e5e2;
    border: 1px solid #34343c;
    padding: 15px;
    border-radius: 8px;
    z-index: 999999;
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
    box-shadow: 0 8px 24px rgba(0,0,0,0.5);
    width: 300px;
`;

panel.innerHTML = `
    <h3 style="margin: 0 0 10px 0; font-size: 14px; color: #6fb3ad;">📦 Knowledge Exporter</h3>
    <div style="display: flex; gap: 8px; margin-bottom: 12px;">
        <div style="flex: 1; background: #16211f; border: 1px solid #2c4644; border-radius: 6px; padding: 8px; text-align: center;">
            <div style="font-size: 10px; color: #97949e; text-transform: uppercase; letter-spacing: 0.03em;">Tabs</div>
            <div id="tab-count" style="font-size: 18px; font-weight: bold; color: #a4d1cc;">0</div>
        </div>
        <div style="flex: 1; background: #16211f; border: 1px solid #2c4644; border-radius: 6px; padding: 8px; text-align: center;">
            <div style="font-size: 10px; color: #97949e; text-transform: uppercase; letter-spacing: 0.03em;">Entries</div>
            <div id="entry-count" style="font-size: 18px; font-weight: bold; color: #a4d1cc;">0</div>
        </div>
    </div>
    <p id="export-status" style="margin: 0 0 12px 0; font-size: 12px; color: #97949e;">Switch to a tab, then click capture.</p>
    <div style="display: flex; gap: 8px;">
        <button id="capture-btn" style="flex: 1; background: #238636; color: white; border: none; padding: 8px; border-radius: 4px; cursor: pointer; font-weight: bold; font-size: 12px;">📸 Capture Tab</button>
        <button id="finish-btn" style="flex: 1; background: #da3633; color: white; border: none; padding: 8px; border-radius: 4px; cursor: pointer; font-weight: bold; font-size: 12px;">💾 Download</button>
    </div>
`;

document.body.appendChild(panel);

const statusEl = panel.querySelector('#export-status');
const captureBtn = panel.querySelector('#capture-btn');
const finishBtn = panel.querySelector('#finish-btn');
const tabCountEl = panel.querySelector('#tab-count');
const entryCountEl = panel.querySelector('#entry-count');

function updateTotals() {
    const tabNames = Object.keys(allTabsData);
    const totalEntries = tabNames.reduce((sum, name) => sum + allTabsData[name].length, 0);
    tabCountEl.textContent = tabNames.length;
    entryCountEl.textContent = totalEntries;
}

// 3. Capture button logic
captureBtn.onclick = () => {
    let activeTabName = "General";
    const activeTab = document.querySelector('.page_tab__StlPv[data-active="true"]');
    if (activeTab) {
        activeTabName = activeTab.textContent.trim().replace(/[^a-zA-Z0-9]/g, "_");
    }

    const cards = document.querySelectorAll('.page_knowledgeCard__QPCDk');
    const scrapedCards = [];

    cards.forEach((card, cardIndex) => {
        const contentEl = card.querySelector('.page_content__BdS5v');
        const metaEl = card.querySelector('.page_meta__chVMO');

        scrapedCards.push({
            id: cardIndex + 1,
            content: contentEl ? contentEl.innerText.trim() : "",
            metadata: metaEl ? metaEl.innerText.trim() : ""
        });
    });

    allTabsData[activeTabName] = scrapedCards;
    updateTotals();
    statusEl.innerHTML = `✅ Captured <b>${activeTabName}</b> (${scrapedCards.length} entries). Switch tabs and capture next!`;
    console.log(`Captured tab: "${activeTabName}" with ${scrapedCards.length} items.`);
};

// 4. Finish and download logic
finishBtn.onclick = () => {
    const exportPayload = {
        Shape: shapeName,
        ExportedAt: new Date().toISOString(),
        Tabs: allTabsData
    };

    const fileName = `${shapeName}_Knowledge_Complete_Export.json`.replace(/\s+/g, "_");
    const dataStr = "data:text/json;charset=utf-8," + encodeURIComponent(JSON.stringify(exportPayload, null, 2));

    const downloadAnchor = document.createElement('a');
    downloadAnchor.setAttribute("href", dataStr);
    downloadAnchor.setAttribute("download", fileName);
    document.body.appendChild(downloadAnchor);
    downloadAnchor.click();
    downloadAnchor.remove();

    panel.remove();
    console.log(`🎉 Knowledge export downloaded as: ${fileName}`);
};

})();
4

Capture each tab, then download

Click Capture Tab on your current tab, switch to the next one in the app, and click it again — repeat for every tab you want in the export. When you're finished, click Download to save the combined file and close the panel.

What you'll get

The download is a single JSON file shaped like this:

{
  "Shape": "YourShapeName",
  "ExportedAt": "2026-09-17T04:12:00.000Z",
  "Tabs": {
    "General": [
      { "id": 1, "content": "...", "metadata": "..." }
    ],
    "Relationships": [ ... ]
  }
}
Shape
The name detected from the page you exported from.
ExportedAt
The exact time the file was downloaded.
Tabs
One entry per tab you captured, each holding that tab's knowledge cards in order.

Good to know

  • Reloading the page resets the panel. Everything you've captured lives in that browser tab's memory only — if you refresh or navigate away before downloading, you'll need to paste the script again and start over.
  • Order doesn't matter. Capture your tabs in whatever order is convenient — each one is stored under its own name in the final file.
  • Re-capturing a tab overwrites it. If you click Capture Tab twice on the same tab, the second capture replaces the first rather than duplicating it.
  • Only Knowledge cards are captured. This script reads the content and metadata of knowledge entries — it doesn't export personality settings, images, or anything outside the Knowledge page.
